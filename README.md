# 学院综测 Excel 批量核对

面向学院综合素质评价审核的 Windows 桌面工具。它把多 Sheet 的参考大表与多份个人申报表放在一起核对，帮助审核者快速定位活动、等级、分数和证明材料的差异。核对在本机完成，运行时无需上传工作簿。

> **项目状态：** 源码可运行；尚未发布经过完整桌面验证的 EXE。不同学校、学年的模板可能不同，请先用脱敏样表检查列设置与导出结果。

## 能做什么

- **批量匹配：** 一次导入参考大表和多份个人表。完全一致的条目标绿，待确认项标橙，确认有问题的条目标红；文字型参考分数（如“评审认定”）单独列为待评审。
- **人工核对：** 显示相似候选、差异和参考表位置，可确认对应项、标记不匹配或暂时跳过。
- **证明审核：** 根据个人总表的“大类＋序号”找到分类证明 Sheet。内嵌图片可缩放、拖动查看；点击“证明足够／不足”后自动跳到下一条待审。
- **原表定位：** 双击活动条目，或右键选择总表／证明位置，可用桌面版 Microsoft Excel 打开原始工作簿并选中对应单元格。浮动图片无法在程序内预览时，仍可跳到对应的证明行。
- **保留审核记录：** 保存 JSON 进度、导出带颜色和备注的审核副本。长期等价写法规则支持大类、小类、活动名称和等级，启动时会提醒检查已加载的规则。

## 输入文件与适用范围

支持 `.xlsx` 和 `.xlsm`；暂不支持旧式 `.xls`。程序不要求个人表来自手机 App。

| 文件 | 默认结构 | 可调整内容 |
| --- | --- | --- |
| 参考大表 | 多个 Sheet；各 Sheet 的表头和列结构相同，Sheet 可代表不同大类 | 表头行；大类、小类、活动名称、等级、参考分数所在列 |
| 个人申报表 | 一个“总表”及若干分类证明 Sheet；同一批个人表使用相同模板 | 总表名称与表头行；大类、序号、活动、等级、分数、备注所在列；大类与证明 Sheet 的映射 |
| 分类证明 Sheet | A 列为序号，B 列为证明材料；序号与总表同一大类下的序号对应 | 可设置大类与证明 Sheet 的映射；证明页的列位目前固定 |

默认示例中，参考大表使用 D～H 列表示“大类／小类／活动名称／等级／参考分数”；个人总表使用 A～F 列表示“大类／序号／活动名称／等级／申报分数／备注”。实际列号以“设置格式”窗口为准。个人总表的大类名称末尾如有“（10分）”，读取时会忽略这段分数。

图片预览支持项目已适配的 WPS 和 Excel 单元格内图片结构。**浮动图片不会被自动判定为某条活动的证明**，需打开原表人工查看；若证明 Sheet 或序号不能唯一确定，程序会提示检查映射。

## 从源码运行

需要 Windows 和 Python 3.11 或更新版本。审核、图片预览和导出不依赖 Microsoft Excel；“在 Excel 中定位”功能需要安装桌面版 Microsoft Excel。

在本目录的 PowerShell 中执行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[desktop]"
.\.venv\Scripts\python.exe batch_review_desktop.py
```

若使用其他 Python 3.11+ 版本，可将第一条命令中的 `py -3.11` 换成相应的 `python`。现有 `batch_review_desktop.cmd` 是针对项目本地 `.conda-env` 的启动器；使用上述 `.venv` 时请直接运行 Python 命令。

## 审核流程

1. 选择参考大表，加入本批全部个人表。导入时可选择文件夹，一次备份参考表和个人表。
2. 打开“设置格式”，确认列号、表头行与分类证明 Sheet 的对应关系，再开始扫描。
3. 在“活动与分数”页处理橙色候选；分数差异请查看候选的“差异”列。需要时可预览后“忽略本差异”，或将参考值“应用到原表”。
4. 在“证明审核”页查看图片并判断足够／不足；可用滚轮缩放、鼠标拖动和“100%”按钮看细节。
5. 保存进度，并将审核副本导出到自选文件夹。证明不足的条目会在副本备注中标记。

**文件改动范围：** 导入、扫描、人工确认和 Excel 跳转本身不保存原表。“应用到原表”会在预览与确认后直接写入原始个人文件，因此建议先使用导入时提供的备份功能。“导出审核副本”会生成新文件，不覆盖原表。进度文件记录输入文件指纹；原文件在外部变化后，需要重新扫描。

长期规则保存在 `%APPDATA%\CollegeReview\batch_review_settings.json`。首次启动新版时，若旧配置位于源码目录或 EXE 旁的 `configs/batch_review_settings.json`，且新位置尚无规则，程序会复制旧规则；旧文件保留，新位置已有规则绝不覆盖。跨学年使用前请核对规则是否仍适用；这些本地规则不应提交到公开仓库。

## 开发与测试

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[desktop,dev]"
.\.venv\Scripts\python.exe -m pytest -q
```

请从**本项目目录**运行测试；测试使用临时生成的工作簿，不需要个人真实数据。

| 路径 | 用途 |
| --- | --- |
| `batch_review_desktop.py` | 学院批量核对界面 |
| `excel_navigation.ps1` | Windows Excel 原表定位 |
| `src/activity_matcher/batch_core.py` | 扫描、匹配、进度和审核副本 |
| `tests/` | 自动测试 |
| `review_desktop.py` | 另一套针对手机导出表的核对入口 |
| `run.py`、`interactive_match.py` | 历史评分表清洗与检索原型 |

历史表格检索原型可通过 `python run.py inspect <文件.xlsx>`、`python run.py clean <文件.xlsx>` 和 `python run.py match <活动名称>` 试用；它与学院批量审核入口相互独立。

### 构建 Windows 发布包

维护者可在安装 PyInstaller 后运行 `build_release.ps1`。默认生成 `dist/CollegeReview/` 文件夹版；验证规则跨重启保存、Excel 原表定位和证明图片后，再运行 `build_release.ps1 -OneFile` 生成单文件版。脚本会把 `excel_navigation.ps1` 作为只读资源放进发布包，不会把个人长期规则打进去。

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\build_release.ps1
```
